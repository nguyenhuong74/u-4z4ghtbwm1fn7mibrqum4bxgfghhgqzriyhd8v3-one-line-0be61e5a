An entry for the make.fun bounty
[One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a):
one original, self-contained one-liner — a printer that jams at the
worst possible moment and turns a resignation into a plea to stay.

## The joke

> My printer jammed while printing my resignation letter — even the hardware is begging me to stay.

97 characters, no trailing newline.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line above to
`/output/entry.txt`, creating `/output` if needed. No network, no
randomness, no time, no reads outside this repository: every run writes
identical bytes.
